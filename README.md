## 📌 About This Repository

This repository documents my **ongoing learning journey with Java, Spring Framework, and Spring Boot**. It is being updated continuously as I learn, practice, experiment, and build new things.

The goal is simple:

* Learn consistently
* Practice by writing code
* Understand concepts deeply
* Build real development confidence
* Share the journey publicly

This is not a finished repository; it is a **living project** that grows with every new commit.

---

## 🎯 What You Will Find Here

* Java and Spring practice code
* Hands-on experiments
* Learning notes through code
* Small demos and implementations
* Daily progress updates
* Real development exploration

As the journey continues, new examples and improvements will keep getting added.
