## 🌱 About This Repository

<p align="center">
  <img src="https://capsule-render.vercel.app/api?type=rect&color=0:0f2027,100:2c5364&height=2&section=header" width="80%"/>

> **This is not a finished course. This is a living, breathing journey.**

This repository is a **personal and public learning log** that documents an end-to-end exploration of the **Spring ecosystem** — starting from the very first concept of what Spring even is, all the way through Spring Core internals and Spring Boot mastery.

Every commit here represents a real learning milestone. Every file added is a step taken. Whether you are a **complete beginner who has never written a single line of Java** or someone who wants to understand Spring properly from first principles — this space is built for you.

The philosophy here is simple:

- 📖 **Learn by doing** — not just reading slides.
- 🧠 **Understand the why** — not just the how.
- 🔄 **Grow continuously** — this repository is never "done."
- 🤝 **Learn together** — your stars, forks, and questions push this forward.

---

## 💡 Why This Repository Exists

Most Spring tutorials online throw you into annotations and magic without ever explaining what is happening under the hood. That creates developers who can follow tutorials but can't debug, design, or think independently.

This repository was created to **fix that gap** — to build a resource that takes someone with **zero prior Spring knowledge** and walks them, step by step, through every foundational concept before touching Spring Boot.

If you've ever felt lost reading Spring documentation, this is your starting point. If you're a self-taught developer trying to go from tutorials to professional-grade understanding — you're in the right place.

> _"Don't just learn Spring. Understand it."_ — **ADV Indian Coder**

## 🚀 Getting Started

You don't need to be an expert to get started. If you have Java installed, you're ready.

**Clone this repository to your local machine:**

```bash
# Clone the repository
git clone https://github.com/Vinaykumarmahato/springBirthToSpringCoreAndSpringBoot.git

# Navigate into the project directory
cd springBirthToSpringCoreAndSpringBoot
```

**Prerequisites:**
- ☕ Java 17 or above — [Download JDK](https://adoptium.net/)
- 🔨 Maven or Gradle — [Download Maven](https://maven.apache.org/)
- 💻 Any IDE — IntelliJ IDEA recommended — [Download](https://www.jetbrains.com/idea/)

> Open individual folders in your IDE, read the comments, and run the code. That's it. No complicated setup required.
